# Bodycam Tactical FPS Prototype (Unity URP)

Тактический шутер от первого лица нового поколения в стиле игры **Bodycam** и **Unrecord** на движке Unity (Universal Render Pipeline).

---

## 🎯 Ключевые механики

1. **Chest-Mounted Camera (Нагрудная камера):**
   * Точка обзора закреплена на тактическом бронежилете (~1.42 м от земли), а не на уровне глаз.
   * Процедурный боббинг шагов по кривой Лиссажу.
   * Инерция поворота (Rotational Lag) и центробежный крен при резких разворотах.
   * Микровибрации крепления экшн-камеры на бегу.

2. **Deadzone Aiming (Свободный прицел):**
   * Оружие свободно двигается в пределах экранной мертвой зоны (Yaw: +-14 deg, Pitch: +-10 deg).
   * При достижении границ избыточный импульс мыши плавно разворачивает корпус персонажа и камеру.
   * Автоцентрирование оружия при ускоренном движении вперед.

3. **Procedural Weapon Physics (Физика оружия):**
   * Затухающий гармонический осциллятор (Spring Physics) для моделирования импульса отдачи в плечо и подброса ствола.
   * Процедурный Sway и лаг оружия за движениями мыши.
   * Тактический лазерный целеуказатель (LineRenderer) с динамической проекцией точки на геометрии в 3D.
   * Динамический дульный огонь с точечным импульсным освещением окружения.
   * Raycast-баллистика с динамическим конусом разброса (Cone of Fire) и физическими импульсами для объектов с Rigidbody.

4. **VFX & Bodycam Overlay:**
   * Шейдер дисторсии линзы "Рыбий глаз" (Barrel Distortion по модели Брауна-Конради), радиальные хроматические аберрации, виньетка и зернистость сенсора.
   * Тактический оверлей: мигающий индикатор REC (1 Гц), таймкод реального времени с кадрами, уровень заряда батареи, позывной юнита.

## 🚀 Быстрый старт (Сборка сцены в 1 клик)

1. Откройте проект в **Unity 6 / Unity 2023+ (URP)**.
2. В верхнем меню нажмите:
   `Tools -> Bodycam -> Setup Complete Prototype Scene`
3. Откройте сгенерированную сцену:
   `Assets/Scenes/BodycamPrototype.unity`.
4. Нажмите **Play (Ctrl + P)**.

---

## 🎮 Управление

| Клавиша / Ввод | Действие |
|---|---|
| **Мышь** | Свободное наведение ствола (Deadzone Aiming) |
| **W, A, S, D** | Перемещение персонажа с нагруженной инерцией |
| **Left Shift** | Тактический спринт |
| **Left Ctrl** | Присед (плавное опускание камеры) |
| **ЛКМ (Mouse 0)** | Стрельба (автоматический огонь с физической отдачей) |

```text
├── Scenes/

    │   ├── WeaponRecoilSpring.cs     # Пружины физической отдачи

    └── Editor/

```
